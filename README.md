# Brota · mockup navegável

76 telas do app **Brota**, em duas UIs nativas lado a lado: Material 3 Expressive (Android) e Liquid Glass / HIG (iOS).

**Abrir:** https://litorx.github.io/brota-mockup/

- No computador, as duas plataformas aparecem lado a lado, com as notas de handoff em volta. Setas ← → do teclado navegam.
- No celular, aparece só o app, ocupando a tela inteira. A barra de baixo escolhe a tela e a plataforma; o botão ≡ no canto abre os estados de cada tela.

Protótipo em HTML puro, sem build e sem dependência. Só os arquivos deste repositório.
